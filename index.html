Built with security in mind

Your chatbot talks to your customers, so it should be safe. I come from a web and API security background and set up every bot with these protections.

  • No passwords or API keys stored inside the chatbot
  • Phone and email entries checked before they are accepted
  • The bot only discusses your business and refuses off-topic requests
  • Tested against attempts to make it leak data or ignore its rules
